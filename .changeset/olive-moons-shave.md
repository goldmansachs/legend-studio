**BREAKING CHANGE:** Narrow the `legend-ai` public barrel to the symbols that are actually consumed. 64 named exports with no consumer in this repository or in downstream Legend AI plugins have been removed, which stops internal SQL sanitizers, retrieval scoring helpers and chart primitives from being frozen as public API. Three type exports go with them — `UnsupportedEnginePattern`, `MissingParamInfo` and `LegendAIGridAnalysis`. The last four leave with the renderer and single-parse work: `renderStepStatusIcon`, `LegendAIResultGrid` and `LegendAIAnalysisPanel`, whose only consumer was the forked marketplace renderer, and `extractServicePreFilters`, superseded by `extractServiceQuerySchema`. From `LegendAITypes`, `classifyQuestionIntent` is removed and `extractParameterSchemas` is renamed to `buildParameterSchemas`, which takes an already-parsed `RawLambda` and returns synchronously instead of taking query text and returning a promise; the type aliases that module exports are unchanged. The unused `domainContext` field is dropped from `LegendAIProductMetadata`, and `METADATA_SIGNAL_PATTERNS` / `DATA_QUERY_SIGNAL_PATTERNS` become module-private.
